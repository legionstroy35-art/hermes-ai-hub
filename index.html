Hermes AI Hub

Hermes AI Hub is a personal AI assistant operated by its owner for private productivity and task management.

Purpose

The application helps its owner organize tasks, manage personal information, and interact with authorized Google Workspace services.

Google Workspace Integration

Google API access is used only with the account owner's authorization to support requested personal assistant functions.

Availability

This application is intended for personal use and is not offered as a public service.
